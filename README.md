# AI 生图参考库助手（脸 / 服装 / 姿势）

一款专为各大主流 AI 聊天生图平台设计的浏览器用户脚本（UserScript）。在对话界面内直接浏览中文 AI 脸库、服装库、姿势库，一键将选中的参考图及规范化提示词注入输入框。

---

## 核心特性

- **三库合一，即选即用**：
  - **脸库**：涵盖多样化脸型、五官风格与按发长、细分发型层级分类。
  - **服装库**：涵盖四大穿搭体系（现实穿搭、中国历代服饰、二次元·CharaDB、二次元·ギア），配备中英文名称与精准生图关键词；支持多视角（正面/背面/侧面等）服装切换与提示词视角联动。
  - **姿势库**：分类动作参考线稿，支持多视角（正面、斜前、侧面、背面、俯视等）无缝切换，支持 **3D 白模** 与 **深度图（ControlNet Depth）** 双视图一键切换。
- **两级级联动态智能筛选**：
  - 脸库（发长 → 发型）、服装库（大类 → 分类）、姿势库（体系 → 动作分类）全面支持两级联动；切换一级分类后，二级下拉框自动动态提取收敛为对应分类下的专属选项，避免无效跨类筛选。
- **远程 Manifest 动态热更新与精准哈希缓存**：
  - 引入远程配置清单（`manifest.json`），脚本运行时自动检测远端清单，支持文件列表、分类标签与字段映射的零代码热更新；采用基于内容哈希（Hash）的智能缓存机制，远端数据更新时即时感知刷新，无需手动清空缓存。
- **自定义本地图片上传**：
  - 未选择分类时，支持在底部托盘槽位右侧点击 `+` 按钮直接上传本地图片（支持人像、服装、姿势）。
  - 自动生成对应的结构化提示词（如“图X：保留我上传的自定义人像面部特征及五官结构”等），并同样接入格式转换与富文本注入管道。
- **选项卡智能顺延流转**：
  - 选择当前参考图或完成本地上传后，面板自动向后顺延切换到下一个未选择的分类（脸 → 服装 → 动作）。
  - 若下一个分类已选则自动向下跳过顺移；若后方分类均已选满，则平滑停留在当前分类页。
- **全屏高清灯箱与平滑渐进加载**：
  - 点击底部托盘已选择的参考图缩略图，可呼出全屏毛玻璃灯箱放大查看细节。
  - 采用**渐进式两阶段加载**：缩略图即时占位模糊显示（0 延迟），搭配旋转加载环动效；高清原图就绪后淡入平滑替换，避免大图拉取时的等待卡顿；支持按 `Esc` 键、点击背景或关闭按钮退出。
- **图片分级流转机制**：
  - **列表轻量化**：浏览列表与底部托盘严格采用懒加载缩略图（WebP/JPG），保障在海量参考图中流畅滚动，内存占用极低。
  - **填充超清化**：点击“填充到对话框”时，精确抓取对应视角与视图模式的高清原图注入 AI 对话框，确保 AI 生图获得最佳画质与细节参考。
- **结构化提示词自动拼装**：
  - 根据所选参考项自动生成图文对照指令（如：图 1 保留人像五官、图 2 继承服装款式、图 3 参考动作构图；若选择深度图则自动注入 ControlNet Depth 景深说明）。
  - 内置多种渲染风格（写实摄影、日系插画、2.5D 立绘、电影剧照、赛博朋克、白底角色设定等）。
  - 支持追加自定义补充描述，并提供自由修改与一键重置功能。
- **深度适配各类前端富文本编辑器**：
  - 针对 Slate（如通义千问）、Lexical、ProseMirror、Quill 及 React/Vue 受控输入框进行了深度事件模拟与 DOM 选区同步。
  - 支持多种图片注入管道（剪贴板粘贴 `paste`、文件拖拽 `drop`、原生按钮接管 `chooser`、文件控件 `file`），针对不同生图平台定制首选链路，内置自动探测与回退机制。
- **原生级嵌入与自由窗口控制**：
  - 基于 Shadow DOM 构建独立 UI，完全隔离宿主页面的 CSS 污染。
  - 自动适配系统的浅色（Light）与深色（Dark）模式。
  - **浮动图标自由拖动与吸附跟随**：右下角浮动图标支持全屏幕任意拖拽移动，内置 4px 防误触判定（精准区分单击与拖动）；展开面板时图标常驻显示作为定位基准，拖动图标时弹框实时平滑跟随；拖动面板标题栏亦可联动图标协同移动。
  - **弹框智能锚定定位（上方 / 下方 / 左边 / 右侧）**：弹框固定在图标四周，支持智能自动计算或指定方位；具备碰撞自动翻转（Flip）与全向安全视口边界保护（Clamp）。
  - **自由缩放与本地记忆**：支持四周边缘及四角自由拉伸调整尺寸；图标坐标、弹框尺寸与位置自动持久化保存。
  - **便捷收放与防误触**：支持点击悬浮图标、关闭按钮、全局快捷键（`Alt + Shift + R`）或**点击面板外部空白区域自动收起**。
  - **聚光灯遮罩新手引导（Tour）**：首次安装或展开面板时，自动激活全屏暗色聚光灯高亮遮罩，依序聚焦「图库标签切换 → 托盘与本地上传 → 提示词与风格预设 → 一键填充至对话框」四大核心模块，搭配自适应伴随气泡指引。
  - **右上角快捷功能入口与弹窗化架构**：面板右上角集成 **? 操作说明**、**⚙️ 设置** 与 **ⓘ 关于** 独立图标按钮，点击后均以统一风格的模态弹窗呈现；点击操作说明可随时查阅完整指南，并在底部提供随时重新唤起新手引导的入口。
  - **全界面 SVG 图标规范化**：托盘槽位移除按钮由原生字符升级为矢量 SVG 图标，右上角操作图标统一采用 14px 几何对齐规范，消除不同系统间 Emoji 渲染不一致与字重偏差。
  - **底部版本动态呈现与自适应排版**：底部操作栏居中实时读取脚本版本（如 `v0.0.5`），未获取到时不占位不显示；悬浮图标与面板文本强化防折叠自适应排版，避免窗口缩放或狭窄视口下文字被挤压成竖列。
- **完善的控制与安全设置**：
  - **一键重置布局**：在设置中支持一键恢复图标默认位置与弹框默认大小。
  - **图片格式转换**：支持将 WebP 自动转为 JPEG 或 PNG，避免目标平台不兼容。
  - **安全模式**：一键过滤性感、泳装、内衣、魅力写真、双人互动、贴身穿搭及敏感标记素材。
  - **图数限制保护**：支持根据不同平台的参考图上传上限自动告警拦截。
  - **内置诊断工具**：油猴扩展菜单提供一键复制输入框 DOM 结构信息，方便快速排查页面改版兼容问题。

## 安装说明

### 1. 前置依赖
需要现代浏览器及任意一款用户脚本管理器扩展：
- [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)（推荐）
- [Violentmonkey（暴力猴）](https://violentmonkey.github.io/)
- [ScriptCat（脚本猫）](https://docs.scriptcat.org/)

### 2. 安装脚本
1. 打开浏览器脚本管理器的管理面板。
2. 新建用户脚本，清空编辑器中的初始内容。
3. 复制本项目中的 `AI生图参考库助手.js` 完整代码并粘贴保存。
4. 确保脚本处于“启用”状态。

## 使用指南

1. 打开任意受支持的 AI 对话页面（如 Gemini、ChatGPT 或通义千问）。
2. 点击页面右下角的 **“参考库”** 悬浮按钮，或按下快捷键 `Alt + Shift + R` 呼出面板（首次打开会自动触发聚光灯交互新手引导，亦可随时点击右上角问号重温）。
3. **选择参考图**：
   - 切换 **脸 / 服装 / 姿势** 标签页；亦可在底部未选槽位右侧点击 `+` 按钮上传本地专属参考图。
   - 选中卡片或上传本地图后，面板将智能顺延切换到下一个未选择的分类（脸 → 服装 → 动作），若后续已选满则留在当前分类。
   - 在姿势标签页，可自由在 **「3D 白模」** 与 **「深度图 (Depth)」** 视图间一键切换。
   - 使用上方筛选下拉框（支持一级大类与二级子分类动态联动收敛）或搜索框（支持中文、英文、编号匹配）快速查找。
   - 若选中含多视角的姿势或服装，可直接在卡片下方点击视角按钮（如“正面”、“侧面”、“俯视”等），主图与托盘将联动实时切换。
   - 底部托盘实时显示已选择的参考项、所选视角及视图类型（如 `S形站姿 · 俯视 [深度图]`）；点击已选缩略图可呼出全屏灯箱放大查看高清细节，点击 `✕` 即可移除。
4. **配置提示词**：
   - 在提示词折叠栏内选择预设艺术风格，或在输入框内填写补充指令。
   - 文本框会自动生成规范的生图提示词，亦可直接手动编辑。
5. **填充并生成**：
   - 点击面板右下角的 **“填充到对话框”** 按钮。
   - 脚本将按设置下载对应的参考图并注入输入框，同时填入组装好的提示词。
   - 核对无误后，点击平台的生成/发送按钮即可开始出图。

## 偏好设置项

点击面板右上角的 **⚙️ 设置图标** 可呼出弹窗调节以下参数：

- **弹框吸附方位**：
  - `自动计算 (auto)`：根据浮动图标所在位置的最大可用空间，智能选择最舒适的弹出方向。
  - `固定在图标左边 (left)` / `固定在图标右边 (right)` / `固定在图标上方 (top)` / `固定在图标下方 (bottom)`。
- **窗口与图标布局**：点击“重置位置与大小”按钮，一键清空坐标缓存，将图标平移回右下角默认位置，并将弹框恢复为默认尺寸与吸附位置。
- **注入图片方式**：
  - `自动 (auto)`：依次尝试剪贴板粘贴、模拟拖拽、文件上传框。
  - `粘贴 (paste)` / `拖放 (drop)` / `文件框 (file)`：指定单一方式注入。
- **填充顺序**：可配置“先图后文”或“先文后图”，适应不同平台输入框的加载时序。
- **图片格式转换**：支持 `webp→JPEG`、`webp→PNG` 或 `不转换`。
- **最多参考图数**：限制单次最多勾选的图片数量（0 表示不限制，留空表示按平台策略自动处理）。
- **追加到已有输入**：开启后，自动填充的提示词将追加在现有文字之后，避免覆盖草稿。
- **安全模式**：默认开启，自动屏蔽性感、内衣、泳装、魅力写真、双人互动及贴身穿搭等敏感素材。
- **填充后自动发送**：开启后，填充完成将自动触发平台的发送按钮。

## 高级配置与扩展

若需针对新站点或私有镜像源进行微调，可直接编辑脚本源码前部的 `CONFIG` 与元数据：

### 1. 扩展支持的站点
在脚本顶部的 `// ==UserScript==` 元数据区域追加目标站点的 `@match` 规则：
```javascript
// @match        https://your-custom-ai-site.com/*
```
若目标站点的输入框未被通用策略识别，可在 `SITES` 配置表中追加站点规则：
```javascript
const SITES = [
    { re: /your-custom-ai-site\.com/, input: ['textarea#custom-input', 'div[contenteditable="true"]'], attach: ['paste', 'drop'] },
    // ...
];
```

### 2. 配置数据源、动态清单与缓存
```javascript
const CONFIG = {
    sources: [
        'https://ai-pose-gallery.smallyoung.cn/',                 // 私有源（首选）
        'https://ai-pose-gallery.anhao.app/',                     // 官方镜像源（备用）
        'https://cdn.jsdelivr.net/gh/anhao/ai-pose-gallery-zh@main/',
        'https://raw.githubusercontent.com/anhao/ai-pose-gallery-zh/main/',
    ],
    // 远程配置清单（接管文件列表、内容哈希、分类标签与字段映射，支持热更新）
    manifest: 'data/manifest.json',
    files: {
        pose: 'data/pose-zh.json',
        costume: [
            'data/costume-zh.json',
            'data/costume-shisei-zh.json',
            'data/costume-anime-zh.json',
            'data/costume-gia-anime-zh.json',
        ],
        face: 'data/portrait-zh.json'
    },
    sourceLabels: {
        gia: '现实穿搭',
        shisei: '中国历代',
        charadb: '二次元·CharaDB',
        'gia-anime': '二次元·ギア',
    },
    cacheHours: 24, // 远端 JSON 数据本地缓存有效时长（小时，远端哈希更新时自动失效重拉）
};
```

## 故障排查与诊断

- **输入框无法填入文字**：
  - 点击页面输入框获取焦点后，再次点击面板的“填充到对话框”。
  - 亦可直接在参考库面板的提示词输入框中全选复制，手动粘贴至对话框。
- **图片无法上传**：
  - 前往面板“设置”项，将“注入图片方式”由“自动”切换为“拖放”或“文件框”重试。
  - 检查目标站点是否有上传参考图数量上限。
- **使用内置诊断工具**：
  - 在油猴插件菜单中点击 **“诊断：复制输入框结构（反馈问题用）”**。
  - 脚本将提取当前输入框的标签类型、祖先节点链及富文本框架类型（如 Slate、Lexical、Quill 等）并复制到剪贴板，便于调试分析。
- **清空数据缓存**：
  - 若数据源更新或数据异常，可在油猴插件菜单中执行 **“清除数据缓存”** 并刷新网页。
