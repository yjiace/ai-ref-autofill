# AI 生图参考库助手（脸 / 服装 / 姿势）

一款专为各大主流 AI 聊天生图平台设计的浏览器用户脚本（UserScript）。在对话界面内直接浏览中文 AI 脸库、服装库、姿势库，一键将选中的参考图及规范化提示词注入输入框。

---

## 核心特性

- **三库合一，即选即用**：
  - **脸库**：包含不同模式、发型、发长的人像参考。
  - **服装库**：涵盖现实穿搭（1,407 套）与二次元穿搭（440 套 CharaDB）共 1,847 套，配备中英文名称与精准生图关键词。
  - **姿势库**：分类动作参考线稿，支持多视角（正面、斜前、侧面、背面、俯视等）无缝切换，支持 **3D 白模** 与 **深度图（ControlNet Depth）** 双视图一键切换。
- **图片分级流转机制**：
  - **列表轻量化**：浏览列表与底部托盘严格采用懒加载缩略图（WebP/JPG），保障在海量参考图中流畅滚动，内存占用极低。
  - **填充超清化**：点击“填充到对话框”时，精确抓取对应视角与视图模式的高清原图注入 AI 对话框，确保 AI 生图获得最佳画质与细节参考。
- **结构化提示词自动拼装**：
  - 根据所选参考项自动生成图文对照指令（如：图 1 保留人像五官、图 2 继承服装款式、图 3 参考动作构图；若选择深度图则自动注入 ControlNet Depth 景深说明）。
  - 内置多种渲染风格（写实摄影、日系插画、2.5D 立绘、电影剧照、赛博朋克、白底角色设定等）。
  - 支持追加自定义补充描述，并提供自由修改与一键重置功能。
- **深度适配各类前端富文本编辑器**：
  - 针对 Slate（如通义千问）、Lexical、ProseMirror、Quill 及 React/Vue 受控输入框进行了深度事件模拟与 DOM 选区同步。
  - 支持多种图片注入管道（剪贴板粘贴 `paste`、文件拖拽 `drop`、原生按钮接管 `chooser`、文件控件 `file`），针对不同生图平台定制首选链路，内置自动探测与回退机制。
- **原生级嵌入与自由窗口控制**：
  - 基于 Shadow DOM 构建独立 UI，完全隔离宿主页面的 CSS 污染。
  - 自动适配系统的浅色（Light）与深色（Dark）模式。
  - **自由拖拽与缩放**：支持按住顶部标题栏拖拽移动面板；支持四周边缘及四角自由拉伸调整尺寸（左上角及全向手柄）。
  - **位置与尺寸本地记忆**：拖拽位置与缩放尺寸自动持久化保存，下次打开即刻恢复个性化布局，并带视口边缘自适应回正。
  - **便捷收放与防误触**：支持右下角悬浮球（FAB）、全局快捷键（`Alt + Shift + R`）或**点击面板外部空白区域自动收起**。
- **完善的控制与安全设置**：
  - **图片格式转换**：支持将 WebP 自动转为 JPEG 或 PNG，避免目标平台不兼容。
  - **安全模式**：一键过滤性感、泳装、内衣及敏感动作。
  - **图数限制保护**：支持根据不同平台的参考图上传上限自动告警拦截。
  - **内置诊断工具**：油猴扩展菜单提供一键复制输入框 DOM 结构信息，方便快速排查页面改版兼容问题。

## 安装说明

### 1. 前置依赖
需要现代浏览器及任意一款用户脚本管理器扩展：
- [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)（推荐）
- [Violentmonkey（暴力猴）](https://violentmonkey.github.io/)
- [ScriptCat（脚本猫）](https://docs.scriptcat.org/)

### 2. 安装脚本
1. 打开浏览器脚本管理器的管理面板。
2. 新建用户脚本，清空编辑器中的初始内容。
3. 复制本项目中的 `AI生图参考库助手.js` 完整代码并粘贴保存。
4. 确保脚本处于“启用”状态。

---

## 使用指南

1. 打开任意受支持的 AI 对话页面（如 Gemini、ChatGPT 或通义千问）。
2. 点击页面右下角的 **“参考库”** 悬浮按钮，或按下快捷键 `Alt + Shift + R` 呼出面板。
3. **选择参考图**：
   - 切换 **脸 / 服装 / 姿势** 标签页。
   - 在姿势标签页，可自由在 **「3D 白模」** 与 **「深度图 (Depth)」** 视图间一键切换。
   - 使用上方筛选下拉框或搜索框（支持中文、英文、编号匹配）快速查找。
   - 若选中含多视角的姿势，可直接在卡片下方点击视角按钮（如“正面”、“侧面”、“俯视”等），主图与托盘将联动实时切换。
   - 底部托盘会实时显示已选择的参考项、所选视角及视图类型（如 `S形站姿 · 俯视 [深度图]`），可随时点击 `✕` 移除。
4. **配置提示词**：
   - 在提示词折叠栏内选择预设艺术风格，或在输入框内填写补充指令。
   - 文本框会自动生成规范的生图提示词，亦可直接手动编辑。
5. **填充并生成**：
   - 点击面板右下角的 **“填充到对话框”** 按钮。
   - 脚本将按设置下载对应的参考图并注入输入框，同时填入组装好的提示词。
   - 核对无误后，点击平台的生成/发送按钮即可开始出图。

## 偏好设置项

在面板底部的 **“设置”** 栏中可自定义以下参数：

- **注入图片方式**：
  - `自动 (auto)`：依次尝试剪贴板粘贴、模拟拖拽、文件上传框。
  - `粘贴 (paste)` / `拖放 (drop)` / `文件框 (file)`：指定单一方式注入。
- **填充顺序**：可配置“先图后文”或“先文后图”，适应不同平台输入框的加载时序。
- **图片格式转换**：支持 `webp→JPEG`、`webp→PNG` 或 `不转换`。
- **最多参考图数**：限制单次最多勾选的图片数量（0 表示不限制，留空表示按平台策略自动处理）。
- **追加到已有输入**：开启后，自动填充的提示词将追加在现有文字之后，避免覆盖草稿。
- **安全模式**：默认开启，自动屏蔽性感、内衣、泳装及特定双人动作。
- **填充后自动发送**：开启后，填充完成将自动触发平台的发送按钮。

## 高级配置与扩展

若需针对新站点或私有镜像源进行微调，可直接编辑脚本源码前部的 `CONFIG` 与元数据：

### 1. 扩展支持的站点
在脚本顶部的 `// ==UserScript==` 元数据区域追加目标站点的 `@match` 规则：
```javascript
// @match        https://your-custom-ai-site.com/*
```
若目标站点的输入框未被通用策略识别，可在 `SITES` 配置表中追加站点规则：
```javascript
const SITES = [
    { re: /your-custom-ai-site\.com/, input: ['textarea#custom-input', 'div[contenteditable="true"]'], attach: ['paste', 'drop'] },
    // ...
];
```

### 2. 配置数据源与缓存
```javascript
const CONFIG = {
    sources: [
        'https://ai-pose-gallery.smallyoung.cn/',                 // 私有源（首选）
        'https://ai-pose-gallery.anhao.app/',                     // 官方镜像源（备用）
        'https://cdn.jsdelivr.net/gh/anhao/ai-pose-gallery-zh@main/',
        'https://raw.githubusercontent.com/anhao/ai-pose-gallery-zh/main/',
    ],
    files: {
        pose: 'data/pose-zh.json',
        costume: ['data/costume-zh.json', 'data/costume-anime-zh.json'],
        face: 'data/portrait-zh.json'
    },
    cacheHours: 24, // 远端 JSON 数据本地缓存有效时长（小时）
};
```

## 故障排查与诊断

- **输入框无法填入文字**：
  - 点击页面输入框获取焦点后，再次点击面板的“填充到对话框”。
  - 亦可直接在参考库面板的提示词输入框中全选复制，手动粘贴至对话框。
- **图片无法上传**：
  - 前往面板“设置”项，将“注入图片方式”由“自动”切换为“拖放”或“文件框”重试。
  - 检查目标站点是否有上传参考图数量上限。
- **使用内置诊断工具**：
  - 在油猴插件菜单中点击 **“诊断：复制输入框结构（反馈问题用）”**。
  - 脚本将提取当前输入框的标签类型、祖先节点链及富文本框架类型（如 Slate、Lexical、Quill 等）并复制到剪贴板，便于调试分析。
- **清空数据缓存**：
  - 若数据源更新或数据异常，可在油猴插件菜单中执行 **“清除数据缓存”** 并刷新网页。
